# Repository Instructions

## Commands

- Install with `npm ci`; `@groundhogchain/*` packages resolve through GitHub Packages via `.npmrc`, so unauthenticated installs may need a GitHub package token.
- CI uses Node 22 and runs `npm run format:check`, `npm run typecheck`, `npm run test`, then `npm run build`.
- Release workflow runs `npm run build`, `npm run test`, then `npm run typecheck`; do not assume CI and release run checks in the same order.
- Run a focused test with `npx vitest run src/path/to/file.test.ts`; `npm test` always runs the full Vitest suite.
- Regenerate the pinned OpenRPC snapshot with `scripts/regen-openrpc.sh`; it installs `groundhog-open-rpc-spec@0.3.2` from the `groundhog` Cargo registry and formats `specs/openrpc.json`.

## Package Boundaries

- Public package entrypoints are only the root plus `./transaction`, `./transport`, `./contract`, `./signers`, and `./actions`, as defined in `package.json` and `tsup.config.ts`.
- `src/contracts/*` contains generated bindings used by tests; they are not a supported package subpath unless `package.json` and `tsup.config.ts` are changed together.
- Keep ESM source imports with explicit `.js` specifiers; `tsconfig.json` uses `moduleResolution: "bundler"` and strict isolated modules.
- Do not edit `dist/` as source; it is generated by `npm run build`.

## Groundhog Protocol Notes

- Transaction signing signs `serialize(tx, codec.Transaction)`; signed transaction wire bytes use `codec.SignedTransaction`.
- Contract calldata, return data, and event payloads use CXS codecs; protocol transaction/envelope objects use the protocol TXS/XDR codecs.
- Groundhog transactions use `uniquifier` with `block_expiry_height` and `nonce`; do not model this like an Ethereum sequential nonce.
- Canonical tx hashes should follow `@groundhogchain/protocol/utils` (`hashSignedTransaction`) semantics: hash the inner transaction body, not signatures.
- `MockTransport` is deterministic and non-executing; it is useful for unit tests but can hide real RPC wire-shape or hashing bugs.
